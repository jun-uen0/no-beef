# ADR 0002：判定キャッシュはローカルのみ(共有書き込みをしない)

日付：2026-09-15／状態：採用

## 文脈

同じ投稿はタイムライン再描画・RT・引用で何度も流れてくるため、判定キャッシュは必須。当初、GitHubリポや公開スプレッドシートに判定を共有貯蔵する案があった(書き込み競合が懸念点だった)。

## 決定

**判定キャッシュはローカル(IndexedDB)のみ。**キーは正規化テキスト(NFKC・小文字化・空白圧縮)のSHA-256。投稿本文・投稿ID・判定結果を、いかなる外部サービスにも書き出さない。

共有するのは判定ではなく**「賢さ」の方**：語彙リスト・ルール・プロンプトのチューニングを読み取り専用の配布物(GitHub Releases等)として配る。

## 理由

- 他人の投稿本文やIDに「有害」ラベルを紐づけて公開の場に書くのは、**プライバシーとXの規約(コンテンツ再配布)の両面で危険**。書き込み競合以前の問題で、ストア審査でも問題になり得る
- ローカルだけでもヒット率は十分(再描画のたびに同一テキストが来る)
- 配布物方式なら無料・競合なし・審査リスクなし

## 帰結

- `CachePort`で抽象化してあるので、将来共有基盤が本当に必要になればアダプタ追加で対応できる(その際は本ADRを改訂し、匿名化・同意設計を先に行う)
- キャッシュ実装はL1(メモリ・LRU)+L2(IndexedDB)。モデルやルールのバージョンをキャッシュの世代キーに含め、更新時に旧判定を無効化する
